A **modern GUI-based file compression tool** built with Python and `CustomTkinter`.

## 🚀 Features

✅ **Supports Multiple File Types**
- DOCX — Recompresses embedded images inside Word files  
- JPG — Reduces file size using optimized JPEG compression  
- PDF — Compresses embedded images and cleans metadata  
- MP4 — Uses FFmpeg to reduce video file size  

✅ **Modern UI**
- Built with `CustomTkinter` for a smooth, dark aesthetic  
- Animated floating background for a visually appealing experience  

✅ **Progress Tracking**
- Real-time progress bar and compression statistics  

✅ **Cross-Platform Support**
- Works on **Windows**, **macOS**, and **Linux** (requires FFmpeg installed)

---

## 🧩 Tech Stack

- **Python 3.8+**
- **CustomTkinter**
- **Pillow (PIL)**
- **PyMuPDF (fitz)**
- **FFmpeg** (for video compression)
